# 弹窗、侧滑与反馈

## 形态选型

由「内容长度 + 是否需要保留上下文」两个变量唯一决定。

```
需要保留页面上下文，且内容较长 / 可滚动？
├─ 是，从列表行展开 ────────────→ 行内详情弹窗   60%
├─ 是，表单或详情 ──────────────→ 侧滑面板       960px
└─ 否，内容短需居中聚焦
   ├─ 含表格 / 批量清单 ────────→ 居中对话框     500 ~ 1140px
   ├─ 依附触发按钮的一句话确认 ─→ 气泡确认       280px
   └─ 阻断式决策（离开 / 删除）─→ 阻断确认框     —
```

## 侧滑宽度档位

| 宽度          | 定位                         | 场景                                     |
| ------------- | ---------------------------- | ---------------------------------------- |
| 640px         | 小表单                       | 版本发布编辑、告警订阅                   |
| **960px**     | **默认档，新功能从这里起步** | 告警组、任务节点详情、资源规格、权限规则 |
| 1100px        | 宽内容                       | SQL 文本、实例列表、选主机               |
| 1110 / 1200px | 超宽特例                     | 全局监控策略、内存分析                   |

## 侧滑面板规范

- footer 默认「提交」（主色）+「取消」，均 min-width 88px，主按钮在左
- 纯查看时不显示 footer
- 打开期间标记「有弹层」，关闭时走离开确认；明确不需要时可关闭该行为
- 提交逻辑由内容组件自身对外提供

## 居中对话框宽度档位

| 宽度          | 场景                         |
| ------------- | ---------------------------- |
| 480 / 500px   | 批量操作确认、小表单（主流） |
| 600 / 640px   | 集群操作、白名单编辑         |
| 1000 / 1100px | Excel 导入、实例只读预览     |
| 1140 / 1180px | 导出文件列表、申请单预览     |

## 按钮文案规范

| 容器           | 主按钮                                | 次按钮 |
| -------------- | ------------------------------------- | ------ |
| 侧滑面板       | 提交                                  | 取消   |
| 对话框（表单） | 确定 / 确认提交                       | 取消   |
| 对话框（只读） | 关闭（单按钮）                        | —      |
| 气泡确认       | 确认（固定文案）                      | 取消   |
| 阻断确认框     | 语义化：删除 / 离开 / 禁用 / 继续提单 | 取消   |

「提交」与「确定」不可互换：侧滑用提交，弹窗用确定。

## 气泡确认

默认宽 280px（审批类扩到 400px）。普通操作用主色，危险操作用危险色。内容由「标题 + 后果说明」两段构成。

## 离开拦截三态

```
无变更          → 直接离开
有变更          → 弹阻断确认「确认离开当前页」
已有弹层打开    → 跳过确认（避免弹窗套弹窗）
```

表单值变化时标记有变更，提交成功 / 关闭后清除标记。

## 危险操作确认

**不要求用户输入名称做强确认**。删除类操作的标准确认框：

- 标题：「确定删除集群？」，居中
- 按钮：「删除」（危险色）/「取消」，居中
- 内容：左对齐，灰底块列出受影响对象 + 影响说明
- 行内删除用气泡确认：宽 280px，确认按钮危险色 + loading

## 消息反馈

| 场景      | 时长 | 附加                               |
| --------- | ---- | ---------------------------------- |
| CRUD 成功 | 3s   | —                                  |
| 轻量提醒  | 3s   | —                                  |
| 接口错误  | 3s   | 由请求层统一兜底，业务层不重复处理 |
| 提单成功  | 6s   | 不可手动关闭 +「查看详情」外链     |
