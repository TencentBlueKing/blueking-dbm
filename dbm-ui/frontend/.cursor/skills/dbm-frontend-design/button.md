# 按钮体系

## 主题使用

| 主题           | 定位                                 |
| -------------- | ------------------------------------ |
| 默认（无主题） | 次操作                               |
| 主色           | 页面唯一主操作                       |
| 危险色         | 仅不可逆操作（删除、终止），保持稀缺 |
| 警告 / 成功色  | 按钮上不用，只属于标签和状态点       |

主色只给页面唯一主操作。危险色的稀缺性本身就是设计语言，它一出现就代表不可逆操作。

## 位置与形态的对应关系

| 位置                    | 形态                        | 尺寸 / 间距                |
| ----------------------- | --------------------------- | -------------------------- |
| 列表页操作区（最左）    | 主色实心                    | 默认尺寸，次按钮左间距 8px |
| 表格行内 / 操作列       | 文字链接（主色）            | 按钮间 8px                 |
| 批量操作                | 禁用态 + tooltip 说明原因   | 禁用必须给 tooltip         |
| 侧滑 footer             | 主色「提交」+ 默认「取消」  | min-width 88px，间距 8px   |
| 弹窗 footer             | 主色「确定」+ 默认「取消」  | 间距 8px                   |
| 固定底栏（工具箱/详情） | 主色 + 气泡确认包裹的次操作 | min-width 88px，栏高 52px  |
| 详情内联更多操作        | 小尺寸图标按钮              | 内边距 0 6px               |

## 文案语义

全部走国际化，不得硬编码中文。

| 文案            | 用在哪               |
| --------------- | -------------------- |
| 提交            | 侧滑 / 工具箱主确认  |
| 确定            | 对话框 footer 确认   |
| 取消            | 所有次要关闭         |
| 新建 / 添加     | 列表页主操作         |
| 删除 / 终止     | 破坏性操作，配危险色 |
| 复制            | 行内文字按钮         |
| 批量 xxx        | 选中后的批量区       |
| 克隆 / 再提一单 | 单据复用             |

「提交」与「确定」不可互换。

## 尺寸规范

| 规则          | 值             |
| ------------- | -------------- |
| 默认尺寸      | 不传紧凑尺寸   |
| 紧凑场景      | 小尺寸         |
| footer 主按钮 | min-width 88px |
| 按钮间距      | 8px            |

## 权限按钮

涉及资源变更的操作必须接权限控制，不要用裸按钮：

- 无权限时按钮变为 #c4c6cc 文字 / #fafbfd 背景 / #dcdee5 边框
- 点击不执行业务逻辑，而是唤起权限申请流程

## 图标按钮

小尺寸 + 内边距 `0 6px`，只放图标。常用于详情内联的更多操作。
