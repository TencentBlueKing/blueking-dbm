# 框架布局

## 层级结构与固定尺寸

```
body                 100vh / min-width 1366px / overflow hidden
└─ 应用根节点
   ├─ 公告栏（可选）   40px（无公告时为 0）
   └─ 导航框架         height = 100vh - 公告栏高度
      ├─ 顶栏          52px   背景 #0e1525
      └─ 导航主体
         ├─ 侧栏       折叠 60px / 展开 260px   背景 #182132
         └─ 内容容器
            ├─ 面包屑栏 52px   padding 0 14px   背景 #fff   标题 16px/#313238
            └─ 内容区   padding 20px 24px 0   overflow auto
               └─ 业务页面
```

框架固定吃掉 **104px**（顶栏 52 + 面包屑 52）。

> 对应的 HTML 骨架：[assets/page-frame.html](assets/page-frame.html)，新建 HTML 页面时复制此文件，业务内容写进 `content-wrapper`。

## 内容区可用高度

```less
// 普通页面
height: calc(100vh - 公告栏高度 - 52px - 52px);

// 全屏页面：内容区 padding 归零，页面根节点必须 height: 100%
```

内容区**没有 bottom padding**，页面底部留白需要自己补。

## 页面类型

| 类型 | 内容区 padding        | 何时用                       |
| ---- | --------------------- | ---------------------------- |
| 普通 | 20px 24px 0（框架给） | 列表页、配置管理页           |
| 全屏 | 0，页面自管留白       | 工具箱、详情、需要贴边的页面 |

## 面包屑栏扩展点

面包屑栏预留两个可扩展位置，页面需要追加内容时挂载过去，不要改框架本身：

- 标题右侧 — 适合挂当前页面的子标题（如当前工具名）
- 整栏最右侧 — 适合挂页面级操作

## 底部固定操作区

两种形态，规范一致（高 52px、主按钮 min-width 88px、按钮间距 8px、主按钮在左）：

| 形态     | 触发方式           | 适用                   |
| -------- | ------------------ | ---------------------- |
| 滚动吸附 | 滚动到底自动固定   | 工具箱、详情页（优先） |
| 始终固定 | 始终钉在底部       | 内容必然超一屏的页面   |

## 滚动条

| 场景     | 宽 / 高          | thumb                  | hover      |
| -------- | ---------------- | ---------------------- | ---------- |
| 全局默认 | 4px              | #dcdee5                | #979ba5    |
| 横向     | 8px              | #a0a0a0                | —          |
| 深色区域 | 6px → hover 14px | rgb(151 155 165 / 80%) | 90% 不透明 |

深色背景区域（侧栏、深色面板）使用深色主题滚动条。
