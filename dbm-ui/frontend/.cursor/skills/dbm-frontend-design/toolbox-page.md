# 工具箱提单页范式

新建提单页优先复制同族现有页面。同族页面差异极小，只在业务列与单据类型标识。

## 标准骨架（顺序不可调整）

```
顶部提示条（可关闭，说明业务限制）
  ↓ 20px
批量录入入口
  ↓ 16px
垂直表单（label 12px / bold / #313238）
  └─ 可编辑表格（业务列 + 行操作列）
  ↓ 20px
固定底栏 52px：[提交] [重置]
```

- 标准表格型提单页**没有「取消」按钮**，只有「提交」和「重置」
- 「重置」必须套二次确认气泡：标题「确认重置页面」+ 后果说明
- 提交中：提交按钮 loading，重置按钮禁用

## 可编辑表格视觉规格

| 项                | 值                      |
| ----------------- | ----------------------- |
| 表头背景 / hover  | #f0f1f5 / #eaebf0       |
| 单元格字号        | 12px                    |
| 单元格 min-height | 40px                    |
| focus 边框        | #3a84ff                 |
| 错误态背景 / 边框 | #fff1f1 / #ea3636       |
| 行操作列          | 固定右侧，100px         |
| 行图标默认/hover  | #c4c6cc / #979ba5，14px |
| 最少保留行数      | 1                       |

表格必须支持：整表校验、按行校验、按字段校验、按后端错误列表回填行级错误。

列头两种批量入口：

- **批量选择数据** — 列头追加图标入口，选择后批量回填该列
- **统一设置列值** — 列头气泡弹层，一键应用到所有行

## 批量录入弹窗

| 项         | 值                         |
| ---------- | -------------------------- |
| 宽度       | 1200px                     |
| 格式说明区 | padding 16px，背景 #f5f7fa |
| 输入区高度 | 310px                      |
| 覆盖选项   | 复选框「覆盖表格已有数据」 |
| 底部按钮   | 确定 / 取消，各 min 88px   |

应用录入后清空重建表格（强制重渲染），避免残留旧校验状态。

## 校验与提交流程

```
1. 用户点「提交」
2. 整表校验，失败即终止
3. 提交单据
4a. 成功 → 6s 不可手动关闭的成功提示 +「查看详情」外链
         → 原地清空表单，可连续提单
4b. 重复单据 → 弹确认「是否继续提交」，确认后携带忽略标记重提
4c. 失败 → 页面底部（固定栏上方）展示危险色错误条
         → 用户修改表格时自动清除该错误
```

**提交成功不跳转成功页**，原地清空让用户继续提单。只有多步向导的最后一步才展示提交成功页。

## 错误提示的三个层级

| 层级     | 位置                           | 触发                                 |
| -------- | ------------------------------ | ------------------------------------ |
| 单元格级 | 输入框右侧红色感叹号 + tooltip | 必填（值变化时）/ 自定义规则（失焦） |
| 页面级   | 底部固定栏上方危险色提示条     | 提单接口返回错误                     |
| 行级回填 | 错误定位到具体单元格           | 后端返回按行的错误数组               |

必填校验文案统一为「{label}不能为空」，由列组件自动生成，不要每列手写。

## 新增提单页的联动约定

- 单据类型标识（全大写）、页面目录名、路由名、详情展示组件名，四者必须完全一致
- 详情展示组件按单据类型动态匹配，命名即匹配依据
