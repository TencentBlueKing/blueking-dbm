## 四类页面骨架

系统只有 4 种页面骨架，新页面必须归入其中一种，不要发明第五种。

| 骨架       | 判定条件           | 顶层结构                  | 底部操作                     |
| ---------- | ------------------ | ------------------------- | ---------------------------- |
| 列表页     | 展示可筛选的集合   | 操作区 + 表格 + 分页      | 无，操作在行内或批量区       |
| 工具箱提单页 | 提交一次性变更单据 | `SmartAction` 包裹        | 固定底栏 52px：提交 + 重置   |
| 详情页     | 只读展示单个实体   | 灰底摘要栏 + 卡片栈 / Tab | `SmartAction`：克隆 / 撤销等 |
| 配置管理页 | 少量记录的 CRUD    | 操作区 + 表格 + 侧滑表单  | 侧滑 footer：提交 + 取消     |

## 设计令牌

### 间距只有 8 / 16 / 20 / 24

不要出现 10 / 12 / 18 这类中间值。

| 值   | 写法                | 用途                             |
| ---- | ------------------- | -------------------------------- |
| 8px  | `class="mr-8"` / `ml-8` | 按钮之间、图标与文字之间         |
| 16px | `class="mb-16"`     | 操作区与表格之间、卡片之间       |
| 20px | `class="mb-20"`     | 顶部 `BkAlert` 与表单之间        |
| 24px | `padding: 0 24px`   | 页面左右内边距、Tab 容器         |
| 88px | `class="w-88"`      | footer 主按钮 `min-width`        |
| 52px | —                   | 顶栏 / 面包屑 / 固定底栏统一高度 |
| 2px  | `@border-radius-base` | 全站唯一圆角                     |

`common.less` 用 Less 循环生成了 `.pd-0` ~ `.pd-50`、`.mg-`、`.mt-`、`.mr-` 全套原子类（带 `!important`），优先用原子类而不是写行内 style。

### 字号只有 12 / 14 / 16

| 字号 | 变量                | 用途                                       |
| ---- | ------------------- | ------------------------------------------ |
| 12px | `@font-size-mini`   | **内容区基准**：表格、表单 label、详情 KV、Tag |
| 14px | `@font-size-normal` | body 全局默认、部分按钮、工具箱页标题      |
| 16px | `@font-size-large`  | 详情主标题（集群域名、单据类型）、面包屑标题 |

`body` 声明的是 14px，但 `common.less` 把 `bk-table`、`bk-form-label`、`bk-checkbox`、`bk-select` 全局压到 12px。业务页面实际是 12px 的系统，新写的内容区文字默认按 12px 走。

### 颜色一律用 variables.less 的语义 token

禁止硬编码新色值。

| 变量               | 色值    | 语义                                     |
| ------------------ | ------- | ---------------------------------------- |
| `@primary-color`   | #3a84ff | 链接、主按钮、选中态、hover 图标         |
| `@gray-color`      | #979ba5 | 辅助文字、详情 label、meta 信息          |
| `@default-color`   | #63656e | 默认正文、表格正文                       |
| `@light-gray`      | #c4c6cc | 禁用文字、离线行、图标默认态             |
| `@title-color`     | #313238 | 标题、详情 value、加粗 label             |
| `@disable-color`   | #dcdee5 | 边框、分割线、滚动条 thumb               |
| `@danger-color`    | #ea3636 | 删除 / 终止按钮、校验错误                |
| `@success-color`   | #2dcb56 | 状态点、NEW 标签                         |
| `@warning-color`   | #ff9c01 | Alert、已禁用标签                        |
| `@bg-gray`         | #f5f7fa | 内容区背景、说明块背景                   |
| `@bg-dark-gray`    | #f0f1f5 | 详情摘要栏底、表头背景                   |

## 全站铁律

1. **空值渲染 `'--'`**，不要空字符串、不要 `N/A`、不要 `0`。写法 `{{ value || '--' }}`。
2. **所有文案走 `t()`**，不得硬编码中文。
3. **footer 主按钮 `class="w-88"`**，按钮间距 `mr-8` / `ml-8`，primary 在左。
4. **`theme="danger"` 只给不可逆操作**（删除、终止）。全站仅 11 处，稀缺性即语义。
5. **行内操作用 `text` + `theme="primary"`**，不要用实心按钮。
6. **涉及资源变更的操作用 `AuthButton` + `action-id`**，不要用裸 `BkButton`。
7. **禁用按钮必须配 `v-bk-tooltips`** 说明禁用原因。
8. **非 fullscreen 页面不要再套 `padding: 24px`**，框架已给 `20px 24px 0`，会叠加成 44px。

## 已知技术债（沿用现状，不要扩散）

- 表格有两代栈并行：新页面用 TDesign 的 `DbTable/IndexNew.vue`，老页面用 bkui-vue 的 `DbTable/index.vue`。**新建页面一律对齐新栈**。
- 路由 meta 的 `isMenu` 无消费方、`skeleton` 对应的骨架屏已在 `db-router-view` 中被注释，不要再新增这两个字段。
- 全局样式 `.db-icon-button` 在模板中零使用，图标按钮实际写法是 `size="small"` + `style="padding: 0 6px"`。
