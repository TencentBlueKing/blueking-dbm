# 集群参数运行值与应用设定值

需求：TAPD 139203765（1020452995139203765）。仅 MySQL / TenDBCluster 的集群层，业务、模块配置和其它 DB 不启用。

## 已确认运行值查询协议

2026-11-05 用户确认：`POST /apis/configs/get_level_config_with_cluster_runtime/` 沿用 `get_level_config` 的入参和返回外层结构，仅在 `conf_items` 中增加字段；只能请求 `level_name: 'cluster'`，其它层级会报错。

- `conf_value_runtime?: string | null`：运行值按原始字符串展示，不拆分，不从设定值生成运行值。2026-11-05 实际响应补充：无运行值返回 `null`；`null`、缺失及空字符串映射为空数组，显示 `--`，不显示未知状态感叹号；字符串 `0` 是有效值。
- `flag_difference?: -1 | 0 | 1`：1 表示不一致，0 表示一致并无需应用，-1 表示未知；字段缺失按未知展示，不由前端比较字符串推断。
- `runtime_error?: string`：实际响应位于 `data.runtime_error`，与 `conf_items` 同级（如 `tendbha/MySQL-5.7 not support runtime config`）；映射兼容参数项错误并追加到运行值 Tooltip，不因错误重新显示无值感叹号。
- `configs.ts` 独立定义 `getLevelConfigWithClusterRuntime`，在类型层限制 `level_name`；旧接口请求不变。
- `ParamTable.vue` 仅在运行值能力白名单及集群层调用新接口，将返回字段映射到展示模型。字段未返回时不填设定值或虚构数据。

## 前端先行边界

2026-10-28 用户确认：后端协议尚未确定，先实现一版前端，后续协议补充后再改。

- `src/views/db-configure/components/ParamTable.vue`：集群白名单、设定值改名、运行值列、批量恢复默认范围、应用确认预览；重新加载配置时更新运行值并关闭旧预览。
- `RuntimeValue.vue`：只展示参数级后台结论，不计算语义相等，不汇总实例结论。Tooltip 绑定运行值文字，不绑定铺满单元格的容器；按钮随内容收缩，长值仍省略。
- 运行值提示文案按需求 3.4 节消费后台状态：不一致显示「与设定值不一致」；无法判断显示「实例运行值未完全获取，无法判断是否全部与设定值一致」。部分实例失败与语义等价表达尚无确认字段，不推断这些标志。
- `RuntimeValueDetail.vue`：挂在当前集群详情内部，宽 70%，无额外遮罩；捕获点击和 ESC 仅关闭明细；路由详情以详情根容器为边界。当前查询未提供实例明细，不生成虚构实例或获取时间。
- `ApplyConfigDialog.vue`：参数快照预览；应用按钮禁用并说明待 PEER 确认，不创建虚假任务、不弹应用成功；一致参数和只读参数不进入应用预览。
- `runtime-config.ts` 只是前端展示模型，不是 API 返回字段；一致性只消费后台 `flag_difference`。
