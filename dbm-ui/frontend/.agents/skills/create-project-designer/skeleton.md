# 页面骨架资源

## 何时需要

项目存在**全局应用框架**（顶栏、侧栏、面包屑等每个页面都套的外壳）时才做。纯组件库类项目跳过本阶段。

价值：新建页面时直接复制骨架就得到与产品完全一致的框架，不必重新拼装。

## 自包含原则

骨架必须脱离原项目仍能正确渲染，因此把依赖资源**复制进** skill 的 `assets/`，用相对路径引用：

```
assets/
├── page-frame.html     骨架本体
├── iconfont/           图标字体（样式文件 + 字体文件）
└── <logo 文件>         真实 logo 图片
```

不要在骨架里引用原项目路径、CDN 或依赖包内的资源。

## 产物页面单文件交付

skill 的 `assets/` 是资源库，骨架用相对路径引用没问题；但**用骨架产出的 HTML 原型必须交付为单个独立文件**，不允许 iconfont/、logo 等附带资源跟着一起给出：

- 图标字体：woff 转 base64 内联进 `@font-face`，图标规则只保留页面用到的，不要全量内联
- 图片：转 base64 data URI 直接写进 `<img src>`
- 内联完成后删除复制出来的资源文件，只留一个 html

这条规则要写进产物 skill 的铁律与自检清单，让每次新建页面都默认遵守。

## 骨架内容要求

- **零构建依赖**：纯 HTML + 内联 CSS + 少量原生 JS，双击即可打开
- **设计令牌落为 CSS 变量**：色板、圆角等定义在 `:root`，新页面直接取用
- **数值全部来自源码**：高度、宽度、内边距、色值、字体栈、过渡曲线，逐项对齐
- **图标用真实图标资源**：不要手绘 SVG 替代
- **交互状态齐备**：选中态、hover 态、折叠态都要能实际触发
- **标注扩展点**：框架预留的挂载位置用注释标出
- **业务内容区留空**：只给容器，注明「业务内容写在这里」

## 1:1 校验流程

**必须做**，肉眼过一遍不算校验。

1. 向用户索要真实产品截图。截图不清晰时裁剪放大再辨认，不要猜：

```bash
sips -c <高> <宽> --cropOffset <y> <x> <原图> --out <裁剪图>
sips -z <放大高> <放大宽> <裁剪图> --out <放大图>
```

2. 起本地静态服务（浏览器工具通常禁止 `file://`）：

```bash
python3 -m http.server <端口>
```

3. 浏览器打开并截图，与真实截图逐项比对
4. 有偏差就回源码取值修正，不要在骨架里凭手感调
5. 交互状态（折叠等）单独触发后再截一次
6. 校验完毕关闭服务：`lsof -ti :<端口> | xargs kill`

## 高频偏差点

比对时重点看这些位置，它们最容易出错：

| 位置       | 易错点                                                       |
| ---------- | ------------------------------------------------------------ |
| 选中态     | 是纯色底还是渐变，方向与起止色                               |
| 箭头图标   | 细线箭头与实心三角容易混用，放大看清                         |
| 图标列宽   | 侧栏图标列宽度常等于折叠后的侧栏宽度，两者必须一致           |
| 阴影       | 面包屑栏一类的浅阴影极易漏                                   |
| 内容区底色 | 白底还是浅灰底，看清                                         |
| 二级菜单   | 展开时容器整体是否换底色                                     |
| 计数标签   | 高度、圆角、底色，以及选中态下是否反色                        |
| 分组标题   | 用 margin 还是 padding 影响 hover 区域宽度                    |
| 文案       | 逐字核对，含括号内的补充信息                                 |

## 元素增删纪律

**只还原截图里存在的元素**。截图看不清就放大，被裁切就索要完整图，都不行则如实标注：

```html
<!-- 截图中该分组以下被截断，菜单项待补充 -->
```

不要用「看起来应该有」的元素填空。凭低清截图臆造菜单项是最常见的返工原因。

- layout.md 层级结构下方给出骨架文件指引
