# 按钮

| 主题 | 用在 |
| --- | --- |
| 默认 | 次操作 |
| 主色 | 页面唯一主操作 |
| 危险 | 仅删除 / 终止 |
| 警告 / 成功 | 按钮不用，只给 Tag 和状态点 |

| 位置 | 形态 |
| --- | --- |
| 列表操作区最左 | 主色实心 |
| 行内 / 操作列（≤3） | 文字链接，间距 8px |
| 行内 >3 | `MoreActionExtend`（触发器 20px 圆） |
| 批量 | 未选中禁用 + tooltip |
| 侧滑 footer | 「提交」+「取消」 |
| 弹窗 footer | 「确定」+「取消」 |
| 工具箱 / 详情底栏 | 主色 + `DbPopconfirm` 包次操作 |

**所有 footer / 吸底栏同一套几何**：栏高 52px，主按钮在左、min-width 88px（`w-88`），按钮间距 8px。

「提交」与「确定」不可互换。默认尺寸，紧凑场景才 `size="small"`。

资源变更用 `Auth*` 而非 `disabled`，重置与阻断式确认的按钮形态见 [interaction.md](interaction.md)。
