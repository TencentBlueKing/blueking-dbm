## 摘要栏

背景 `#f0f1f5`，padding `16px 60px 16px 20px`。主标题 16px / 700 / #313238 / 行高 24。meta 12px / 行高 20，label #979ba5、value #313238，项间距 40px。

## KV

每项 50%、行高 32px（或 20 + padding-top 6）。label 右对齐、右侧 8px、**运行时取同组最宽**、色 #4d4f56；value #313238；空值 `--`。紧凑表：行高 32，首列 100px，其余奇数列 150px。

单据详情三段式：基本信息（三列 KV）→ 需求信息（按类型匹配）→ 实施进度，卡片间距 16px，内容 `padding-left: 116px`。底栏：克隆 / 撤销 / 终止。字号 12px。

集群详情：卡片式 Tab，`padding: 0 24px`。运行状态用 `ClusterInstanceStatus`，存活用 `DbStatus`。整页无权限用 `PermissionCatch`。

分组标题只用加粗 + #313238，间距 20px，**不用** `.title-spot` 竖线（那是工具箱表单）。
