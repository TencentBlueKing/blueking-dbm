# 工具箱提单页范式

新建提单页优先复制同族现有页面。同族页面差异极小，只在业务列与单据类型标识。

## 标准骨架（顺序不可调整）

```
顶部提示条（可关闭，说明业务限制）
  ↓ 20px
批量录入入口
  ↓ 16px
垂直表单（label 12px / bold / #313238）
  └─ 可编辑表格（业务列 + 行操作列）
  ↓ 20px
固定底栏 52px：[提交] [重置]
```

- 标准表格型提单页只有「提交」和「重置」，没有「取消」
- 重置用 `DbResetButton`；提交中提交 loading、重置禁用
- 分组标题 `.title-spot`（不要和详情页分组标题混用）；底栏 `SmartAction` 高 52px

## 可编辑表格视觉规格

| 项                | 值                      |
| ----------------- | ----------------------- |
| 表头背景 / hover  | #f0f1f5 / #eaebf0       |
| 单元格字号        | 12px                    |
| 单元格 min-height | 40px                    |
| focus 边框        | #3a84ff                 |
| 错误态背景 / 边框 | #fff1f1 / #ea3636       |
| 行操作列          | 固定右侧，100px         |
| 行图标默认/hover  | #c4c6cc / #979ba5，14px |
| 最少保留行数      | 1                       |

表格必须支持：整表校验、按行校验、按字段校验、按后端错误列表回填行级错误。

列头两种批量入口：

- **批量选择数据** — 列头追加图标入口，选择后批量回填该列
- **统一设置列值** — 列头气泡弹层，一键应用到所有行

## 批量录入弹窗

| 项         | 值                         |
| ---------- | -------------------------- |
| 宽度       | 1200px                     |
| 格式说明区 | padding 16px，背景 #f5f7fa |
| 输入区高度 | 310px                      |
| 覆盖选项   | 复选框「覆盖表格已有数据」 |
| 底部按钮   | 确定 / 取消，各 min 88px   |

应用录入后清空重建表格（强制重渲染），避免残留旧校验状态。

## 提交后的反馈形态

- 成功 → 6s 不可手动关闭的成功提示 +「查看详情」外链，**不跳转成功页**，原地清空表单可连续提单
  （只有多步向导最后一步才展示成功页）
- 失败 → 页面底部、固定栏上方展示危险色错误条，用户修改表格时自动清除
- 错误三层递进：格子感叹号 → 底栏错误条 → 后端按行回填。必填文案「{label}不能为空」，由列组件生成

提交时序、重复单据确认这些由提单 hook 承担，实现见 `dbm-ticket-developer`。
