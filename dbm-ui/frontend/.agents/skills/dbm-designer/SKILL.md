# DBM 前端设计规范

运维控制台：最小宽 1366，内容区 12px。一致性来自约束——四种骨架、封闭令牌、复制同族页面，禁止第五种结构和新色值。

深色导航 → 浅灰画布 `#f5f7fa` → 白底工作面。导航色不进内容区。

动手顺序：归骨架 → 选容器 → 只用令牌 → 用现成组件 → 反馈落在起因层（格子 → 页面条 → Toast，不叠两层）。

本 skill 只定「长什么样、怎么反馈」，不管实现怎么落。**架构与代码逻辑归 `dbm-frontend-developer`**，
其余边界与各 skill 分工见 `AGENTS.md`「技能索引」。

## 四类页面骨架

新页面必须归入一种。服务申请宫格、面包屑下 Steps、左表右预览选择器是特例或容器，不是第五种骨架。

| 骨架 | 判定 | 结构 | 底栏 |
| --- | --- | --- | --- |
| 列表页 | 可筛选集合 | 操作区 + 表格 + 分页 | 无 |
| 工具箱提单页 | 一次性变更单据 | 提示条 + 表单表格 | 52px：提交 + 重置 |
| 详情页 | 只读单个实体 | 灰底摘要 + 卡片栈 / Tab | 克隆 / 撤销等 |
| 配置管理页 | 少量 CRUD | 操作区 + 表格 + 侧滑 | 侧滑：提交 + 取消 |

## 令牌

源码：`src/styles/variables.less`。布局间距只有 **8 / 16 / 20 / 24**，不要用 10 / 12 / 18 做区块间隙。4 / 6 只给控件内部。32 / 40 / 42 / 52 / 60 是高度不是间距。字号只有 **12 / 14 / 16**（对话框标题 20px 是 bkui 覆盖，业务不要写 20）。圆角 **2px**。

| | 值 | 用途 |
| --- | --- | --- |
| 间距 | 8 | 按钮、图标与文字 |
| | 16 | 操作区与表格、卡片之间 |
| | 20 | 提示条与表单 |
| | 24 | 页面左右、卡片内边距 |
| 高度 | 52 / 88 | 顶栏·面包屑·底栏 / footer 主按钮 min-width |
| 字号 | 12 | **内容区基准**（表格、label、KV、Tag） |
| | 14 | 全局默认、按钮、菜单 |
| | 16 | 面包屑、详情主标题 |

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 主色 | #3a84ff | 链接、主按钮、选中、hover 图标 |
| 辅助 / 正文 / 弱 / 标题 | #979ba5 / #63656e / #c4c6cc / #313238 | meta label、正文、禁用、标题 |
| KV label | #4d4f56 | 详情双列 label，不是 #979ba5 |
| 边框 | #dcdee5 | 分割线、滚动条 thumb |
| 危险 / 警告 | #ea3636 / #ff9c01 | 删除、校验错误 / 提示条 |
| 成功点 / Tag 绿 | #2dcb56 / #14a568 | `DbStatus` / Tag·NEW，不要混 |
| 搜索高亮 | #F59500 | 表格命中（新列不要用 #FF9C01） |
| 浅底 / 深底 | #f5f7fa / #f0f1f5 | 内容区 / 表头·摘要栏 |

派生色、阴影、z-index 见 [tokens.md](tokens.md)。禁止新色值。

## 铁律

1. 空值 `--`，文案走 `t()`。
2. footer 主按钮 min-width 88px，间距 8px，主按钮在左。
3. 危险色只给不可逆操作；行内操作用文字链接，超过 3 个收进 `MoreActionExtend`。
4. 资源变更接 `Auth*`（无权限是申请态，不是 `disabled`）；禁用必配 tooltip。
5. 非全屏页不要再加 24px 内边距（框架已给 `20px 24px 0`）。
6. 接口错误由请求层 Toast，业务层不要再 `messageError`。
7. HTML 原型交付单个文件：iconfont woff 转 base64 且只留用到的图标，图片转 data URI，删掉复制出来的资源。
