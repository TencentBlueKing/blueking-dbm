# 弹窗、侧滑与反馈

形态由「内容长度 + 是否保留上下文」决定：

```
需要保留页面上下文，且内容较长 / 可滚动？
├─ 是，从列表行展开 ────────────→ 行内详情弹窗   60%
├─ 是，表单或详情 ──────────────→ 侧滑面板       960px
└─ 否，内容短需居中聚焦
   ├─ 左表右预览挑资源 ─────────→ 选择器弹窗     80%（1200 ~ 1600）
   ├─ 含表格 / 批量清单 ────────→ 居中对话框     500 ~ 1140px
   ├─ 依附触发按钮的一句话确认 ─→ 气泡确认       280px
   └─ 阻断式决策（离开 / 删除）─→ 阻断确认框     —
```

## 宽度

侧滑：640 小表单 → **960 默认** → 1100 宽内容。对话框：480/500 主流，600/640 集群操作，1000+ 预览。

## footer

侧滑纯查看不显示 footer。气泡确认 280px（审批 400），标题 + 后果说明。各容器的按钮文案与几何见 [button.md](button.md)。

离开拦截、确认分级与删除确认的形态见 [interaction.md](interaction.md)。

## 选择器

左表右预览，照抄 `host-selector/`。外壳 `width="80%"` min 1200 / max 1600，去 header 与 content padding；不可 Esc / 点遮罩关闭。右栏 320–360px。Tab 40px。表格区高 570、padding `0 24px`。入参只读，确定才 emit，点行即勾选，打开不要重拉表格。细节：known-issues `selector-dialog-skeleton`。

## 行内详情

`TableDetailDialog`：60%，可拖到 90%，min 300px。点空白关闭（弹层 / 气泡 / 侧栏除外）。

## Toast

`messageSuccess` / `messageError` / `messageWarn`。CRUD 3s；接口错误请求层统一 3s，业务不要再弹；提单成功 6s 不可关 +「查看详情」。
