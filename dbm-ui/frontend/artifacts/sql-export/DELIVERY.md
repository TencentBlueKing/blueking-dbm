# 138983706 数据导出交付

## 已落地

MySQL（TenDBHA / TenDBSingle）和 TenDBCluster 保留原单据类型和原路由，各自复用共享导出入口。

- 库表模式与 SQL 模式拆成独立组件，KeepAlive 保存各自输入；重置清空两套表单并停止再次回填克隆数据。
- SQL 支持手动输入或单个本地 .sql 文件；UTF-8 读取、非空和 1GB 大小检查，文件内容只读预览。
- 复用现有 BkRepo 凭证与直传实现上传，不调用变更 SQL 校验接口；目录和文件名分别提交。
- 新建默认结果格式 txt、字符集 default；克隆保留已有格式和字符集。
- SQL 提交体不包含库表模式字段；异步获取上传凭证前固定 SQL、集群、格式、字符集和备注快照。
- 服务端 SQL 错误显示语句序号；重复单据确认和成功反馈沿用既有提交 hook。
- 详情按模式展示字段；SQL 内容从已存文件读取，支持失败重试及请求竞态清理。
- 列表、侧滑详情和全屏详情基本信息增加模式展示，历史单据兼容未返回 export_mode 的情况。
- 已补中英文文案与工具箱模式库存登记。

## 未完成的后端依赖

3. 需求允许 SELECT / USE，附件允许 SELECT / USE / SET，但附件说明 make 已发布版本尚不支持 SET。当前提示沿用需求文案，语法及危险语句校验交给实际目标服务端，验收前须确认目标版本规则。

## 人工验收

以下均须分别在 MySQL 和 TenDBCluster 数据导出入口执行。

| 页面 / 操作 | 预期结果 |
| --- | --- |
| 库表模式按原流程选择集群、库、表并提交 | 原导出功能保留，提交体没有 SQL 字段 |
| 两种模式分别输入后反复切换 | 两套输入各自保留，只校验当前模式 |
| 手动 SQL 填写后提交 | 上传 UTF-8 文件，SQL 体只含协议规定字段，默认 txt / default |
| 上传合法 .sql、空文件、非 UTF-8 文件、超过 1GB 文件 | 合法文件可预览提交，其余出现对应错误；空内容无法提交 |
| 请求 SQL 上传凭证期间变更表单输入 | 当前请求的 SQL、集群、格式、字符集、备注保持同一提交快照 |
| 打开 SQL 单据详情并再次提单 | 模式、集群、备注、SQL 内容、已有格式和字符集回填；原始来源暂不能还原 |
| 两个模式填写后重置，再切换模式 | 两套表单均回到默认，不重新填入原克隆单内容 |
| 历史库表单据详情 | 没有 export_mode 也正确显示库表信息 |
| 列表 / 侧滑 / 全屏详情 | 能取到 details 时正确显示模式，未知模式不误标 |
| 服务端拒绝非法 SQL、重复提交 | 非法 SQL 显示语句序号；重复确认沿用原 hook |
